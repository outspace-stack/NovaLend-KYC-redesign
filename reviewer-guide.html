NovaLend KYC redesign

A clickable mobile prototype based on the supplied design screens. This is a demonstration, not a banking service. Use fictional values only. Cameras, uploads, and verification are simulated; no identity data is transmitted.

Try the complete mobile journey

The primary journey

Splash → Login → NovaPay modules → NovaLend → Apply for a Loan → Verify your identity → Confirm your details → Verify your ID → Camera permission → ID capture → Review ID → ID verified → Selfie instructions → Selfie capture → Review selfie → Verifying → You’re all set.

The final Continue returns to the module screen, completing the demonstration. On a phone, the app fills the screen; on desktop, it stays centred at mobile dimensions. You can add it to your phone’s home screen. The prototype works offline after its initial cache finishes loading.

Try the recovery paths

These links open the exact error screens. No testing controls appear in the customer interface.

  • ID capture failure — retry the camera or enter details manually.
  • Camera unavailable — continue with manual ID entry.
  • Connection interrupted — retry the simulated upload or continue later.
  • Upload failed — retry the simulated upload or continue later.
  • Selfie verification failed — retake the selfie or continue later.
  • Manual ID entry — try the ID dropdown and required fields with fictional data.

“Continue later” and “Do this later” return to modules and preserve the current step in this tab. Tap NovaLend to resume. They do not imply server-side saving. For a selfie retake from the review screen, tap the photo; this retains the supplied two-button layout.

Presentation shortcuts

Alt + Shift + 1–5 triggers the error states in the order above. Network errors injected during the selfie flow retry that stage. Direct error links use the ID upload stage by default.

Alt + Shift + R resets the demo. You can also open the start screen. A refresh preserves the current route and sample form entries in the same tab.

Scope and fidelity

The supplied original login, module, and loan images are bundled at their original resolutions. The ID, selfie, FirstBank logo, avatar, and success illustration were extracted from low-resolution overview screenshots and remain softer; original exports are needed for exact sharpness. Simple line icons use locally bundled Lucide equivalents. Layout, copy, navy palette, and mobile navigation follow the supplied screens.

Other banking modules and Contact support have no destination in the supplied designs and do not launch invented flows. Camera flash and switch controls are simulated. No real camera, NIN/BVN lookup, identity verification, loan application, support service, analytics, or backend is connected.
